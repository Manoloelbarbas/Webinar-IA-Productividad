01

De reunión a plan de acción

R

Rol

Actúa como diseñador instruccional, desarrollador senior full stack, arquitecto de software y experto en ejercicios prácticos de IA para clases corporativas.

Debes crear un prompt maestro para que una IA desarrolle una app web siguiendo Desarrollo Guiado por Especificaciones — SDD.

O

Objetivo

Genera un prompt largo, completo y detallado para crear una aplicación llamada “MinutIA”, que transforme transcripciones de reuniones en informes ejecutivos.

El prompt debe obligar a la IA a trabajar por fases: primero especificación, luego diseño, arquitectura, criterios de aceptación, implementación, pruebas y guion de clase.

C

Contexto

El prompt será usado por alumnos en una clase práctica de IA aplicada al trabajo de oficina, usando Claude Code, Cursor, VS Code con IA o herramientas similares.

La app debe funcionar localmente, trabajar solo con texto, permitir pegar una transcripción o cargar un archivo .txt, escribir una instrucción personalizada y generar un informe ejecutivo con resumen, acuerdos, responsables, pendientes, riesgos, próximos pasos y correo de seguimiento

E

Ejemplos / Reglas

El prompt generado debe incluir obligatoriamente estas fases: problema y alcance, Product Spec, UX/UI Spec, Technical Spec, Acceptance Criteria, Implementation Plan, Implementación, Testing Guide y Class Demo Script.

La IA no debe comenzar programando de inmediato. Debe documentar la metodología SDD, crear README.md, SPEC.md, frontend con HTML/CSS/JS, backend con Node.js y Express, validar errores y cuidar que la API Key nunca quede en el frontend.

F

Formato

Entrega como resultado un prompt maestro extenso, profesional y listo para copiar y pegar.

El prompt debe incluir funcionalidades, requisitos, diseño visual premium, arquitectura técnica, estructura de archivos, endpoints, seguridad, criterios de aceptación, guía de prueba, transcripción de ejemplo, guion para el profesor y desafío práctico para alumnos.
